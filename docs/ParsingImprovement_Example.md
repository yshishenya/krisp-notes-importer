## 🎯 Новая проблема: Медиафайлы не копируются

### 🔴 Проблемы ДО исправления медиафайлов

#### ❌ Проблема #4: Узкий паттерн поиска аудиофайлов
**Старый паттерн:** `/^recording\\.(mp3|m4a)$/i`
- ✗ Ищет только файлы с именем `recording.*`
- ✗ Поддерживает только 2 формата: mp3, m4a
- ✗ Не находит видеофайлы
- ✗ Игнорирует файлы с другими именами

#### ❌ Проблема #5: Дубликаты аудиофайлов с одинаковыми именами
**Старая логика:**
```typescript
// ОШИБКА: возвращался originalPath вместо destPath
case 'skip': return originalPath;  // ❌ Неправильно!
case 'overwrite': return originalPath;  // ❌ Неправильно!
```

#### ❌ Проблема #6: Не поддерживались видеофайлы
- Krisp может экспортировать записи встреч как `.mp4`, `.mov`
- Старый парсер их игнорировал
- Пользователи теряли видеозаписи встреч

**Умный поиск по приоритетам:**
